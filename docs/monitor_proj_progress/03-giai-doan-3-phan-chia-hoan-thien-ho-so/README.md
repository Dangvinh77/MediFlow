Nộp báo cáo này cùng bộ hồ sơ Giai đoạn 1, Giai đoạn 2, bảng phân công code, biên bản rà soát chéo và bằng chứng nộp. Không đánh dấu “hoàn thành” nếu traceability, chữ ký duyệt hoặc quality gate còn trống.
