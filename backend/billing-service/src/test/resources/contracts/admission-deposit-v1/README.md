# Inpatient V1 producer fixture

`admission.deposit.requested.v1.json` is copied byte-for-byte from the real inpatient-service
producer fixture at `backend/inpatient-service/src/test/resources/contracts/admission.deposit.requested.v1.json`.
Do not edit this file by hand; pull a fresh copy if inpatient-service changes the wire shape.

Exchange `mediflow.events`, producer `inpatient-service`, envelope `version=1`, routing key
`admission.deposit.requested` equal to `eventType`. `sourceType=ADMISSION_DEPOSIT`,
`sourceId=admissionId=careEpisodeId`. `suggestedAmount` is Inpatient's own suggestion; Billing never
re-prices it, since a deposit has no catalogue price code to validate against.
